# StructPrompt Studio

**StructPrompt Studio** 是一款专为大语言模型（LLM）设计的**无代码文本结构化提取测评工具**。

它旨在解决大模型在处理非结构化文本数据提取时，普遍存在的**格式崩塌（JSON 破裂）**与**内容幻觉（捏造提取结果）**两大核心痛点。
---

## 🌟 核心特性

- **开箱即用的可视化管线**：无需编写任何代码，通过 UI 可视化编辑提取规则，支持随时配置独立字段的系统指令 (Instruction)。
- **防幻觉白名单与自动重写机制**：针对特定字段，你可以启用字典白名单（如：只允许输出`正面`或`负面`）。一旦大模型输出了幻觉或超出白名单的违规词，系统将自动对大模型抛出严重错误，并在上下文内强制其进行最多 3 次打回重写。
- **✨ [NEW] 同义词纠偏**：当出现违规词时，你可以开启该能力。系统会暂缓异常抛出，自动发起一次“后台隐式判别”调用，询问模型违规词是否与你的目标白名单互为同义词。如果判定为同义，它会在后台静默将异形词（如“积极”）自动规约为你的标准规范（“正面”），极大提升合格率与数据清洗效率。
- **高并发实盘测算 (Concurrency Pool)**：支持流式读取超大型本地 CSV 数据集。在测评面板可手动指定并发网络线程数量，压榨 API 极限，高效跑完千条数据的预实验评测。

## 🚀 架构重构 (Tauri Version)

该项目最初基于 `Electron` + `React` 开发，但打包后体积过于庞大（400MB+）。
在本次更新中，我们进行了彻骨的架构迁移：
- **底层引擎更换**：拥抱 **Tauri** (Rust)，通过系统级原生的 WebView2 渲染，将最终 `.exe` 的打包体积极致压缩至 **约 6 MB**！
- **原生跨域穿透**：告别繁重的 Node 代理进程，全面启用 Tauri 原生的跨平台 HTTP Client，实现更安全、更快、完全无视浏览器 CORS 限制的直连通讯链路。

## 🛠 开发与构建指南

本项目适用于 Windows 10 / 11。由于采用了 Tauri 架构，二次开发需要提前配置好 C++ 以及 Rust (Cargo) 编译环境。

### 1. 环境准备
请确保你的电脑已经安装：
- Node.js (v18+)
- Rust (rustup)
- Microsoft Visual Studio C++ Build Tools

### 2. 依赖安装与启动
```bash
# 安装前端依赖
npm install

# 启动本地开发服务器（支持实时热更新，首次启动会自动拉取 Rust 依赖）
npm run tauri dev
```

### 3. 构建发布版
```bash
# 将前端与 Rust 后端编译为一个独立的可执行文件
npm run tauri build
```
编译成功后，产物将默认输出于 `src-tauri/target/release/` 目录下。直接双击即可作为单文件便携软件执行。

本工具属于**纯本地桌面应用**。您配置的 API Key 接口密钥以及测试产生的本地数据，均强加密存储于本机缓存中，且绝不会向任何未经授权的第三方服务器发送。所有的网络通讯均由本机直发至您指定的 LLM Base URL 端点。
