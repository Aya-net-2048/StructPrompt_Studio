# StructPrompt Studio

StructPrompt Studio 是一款专为社会科学研究者、数据分析师设计的**无代码文本结构化提取测试工具**。
通过可视化的卡片界面，你可以轻松将任意表格文本通过LLMs转化为严谨、干净的结构化数据。

## 🌟 核心功能

- 📄 **无代码提取管线**：直接点选需要分析的列，用自然语言说明判定标准，系统底层自动构建提取代码。
- 🛡️ **防幻觉与白名单系统**：自定义白名单词典。如果大模型瞎编乱造，系统将自动进行多轮重发要求模型更正。
- 🚀 **并发功能**：支持自定义调整并发线程数，吃满 API 速率上限。
- 🔒 **本地存储**：你的 API 密钥、测试数据集以及管线规则，**全部安全存储于你的电脑本地浏览器内核中**。
- 📊 **所见即所得**：测试完毕后，一键将 AI 提取的成果与原始数据拼装，直接导出真实的 CSV / JSON 数据表单用于二次分析。

## 🛠️ 安装与运行指南

该项目基于 **React + Electron + Vite** 构建。

### 1. 环境准备
确保你的电脑上安装了 Node.js（推荐 v18 及以上版本）。

### 2. 安装依赖
打开终端，进入项目根目录：
```bash
npm install
```

### 3. 本地开发预览
```bash
npm run dev
```
这将会在本地快速启动 Electron 开发窗口，支持热更新（Hot Reload）。

### 4. 封装独立免安装 EXE（仅限 Windows）
```bash
npm run build:ui
node build_exe.cjs
```
编译打包后的免安装执行文件将会出现在 `release/StructPromptStudio` 目录下，你可以将其整个文件夹打包发给任何研究员直接双击运行。

---
*注：所有敏感配置（API Key、提取指令、模型参数等）由于架构设计仅保留在各使用者的本地 `localStorage` 中*
